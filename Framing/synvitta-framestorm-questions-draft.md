## Four starters (all open — none selected)

### 1. Constraint is who may buy today, not the product

| | |
|---|---|
| **See** | Guiding Q1 ranks three products (E9) |
| **Belief under test** | Product choice is the decision; buyer eligibility is secondary |
| **Supports** | Choice set is SynELISA vs SynArray NBS vs SynArray custom (P1–P3) |
| **Challenges** | Case asks where Synvitta may legitimately offer RUO and how to reach research buyers (Q1); RUO is intended-use (R1); CLIA lab ≠ free to use research kit for diagnosis (R2) |
| **Approach guess** (if this frame later wins) | Map who may buy under which claim first; product scorecard second |

### 2. First win is evidence, not revenue

| | |
|---|---|
| **See** | Speed to first revenue is a criterion; SynELISA = near-term sales (E9, P1) |
| **Belief under test** | Success = first dollar; anything else is stalling |
| **Supports** | Limited resources (E4); SynELISA near-term sales (P1); 90-day actions/metrics (E11) |
| **Challenges** | Models include evaluation/collaboration and lab partnership for regulatory assessment (E10); NBS still needs development/validation/pathway (P2); deliverable asks for a regulatory assumption to verify, not only revenue (E7) |
| **Approach guess** (if this frame later wins) | Define 90-day win as observable proof (eval, data, paid SOW, LOI); revenue is one proof type |

### 3. Brazil is misleading us about U.S. buyers

| | |
|---|---|
| **See** | First commercial efforts in Brazil; now U.S. (E3) |
| **Belief under test** | Brazil tells us who will buy in the U.S. and that the motion transfers |
| **Supports** | Brazil is presented as real commercial history (E3) |
| **Challenges** | No Brazil buyer/claims/results in the case; U.S. FDA/CLIA/RUO warnings are U.S.-specific (E4, R1–R3, E10) |
| **Approach guess** (if this frame later wins) | Brazil = capability clue only; build U.S. buyer map from U.S. claim rules |

### 4. Revenue now also builds the clinical path

| | |
|---|---|
| **See** | Near-term opportunities while building toward future clinical commercialization |
| **Belief under test** | One move can both make money now and advance the clinical path |
| **Supports** | Case explores CLIA-lab / diagnostic-developer collaborations for demand + future pathways (Q2); custom/NBS sit on a clinical arc (P2–P3) |
| **Challenges** | RUO ≠ patient diagnosis (R1); CLIA ≠ clinical use of research kit (R2); NBS still needs a pathway Synvitta lacks (P2); dual-purpose easily smuggles clinical intent |
| **Approach guess** (if this frame later wins) | Count a dollar as path-building only if counterpart + claim language stay legitimate and create a transferable asset; else split cash-now from path-later |
