## Primary hypothesis (four parts)

> We believe **[customer or partner type]** would **[buy / evaluate / co-develop]** within 90 days
> **because** ___.

| Part | Content |
|---|---|
| 1. Claim + **because that can fail** | |
| 2. Evidence that puts it first | |
| 3. Decision change — what Synvitta does **differently** | |
| 4. Kill condition — we would be wrong if… | |

### Test horizons

| Horizon | Kill / check | Pass / fail / not yet |
|---|---|---|
| **~4 hours** (desk / case window) | e.g. named U.S. buyers of comparable products exist or not | |
| **90 days** (only after real motion) | e.g. eval / SOW / refusal under claim rules | |

If either horizon is “neither / untestable,” rewrite the hypothesis.
