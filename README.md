# R2L Y2 4 Synvitta

U.S. market-entry case for **Synvitta Diagnostics** (UF Rise to Leadership MBA).

**Stage now: prepare only.** Frame, issue, problem statement, opportunity, customer, how, and
90-day plan are **not decided**. This repo holds facts, rails, and framestorm drills for when the
team decides.

**Hard outs (from case):** no FDA filing strategy, no detailed financial forecast, no nationwide
market sizing.

**Later deliverable shape (when solving is asked):** one opportunity · one customer/partner · how ·
90-day plan — chosen from the case’s three options (SynELISA RUO · SynArray NBS · SynArray custom).

## How to use this repo in prepare

1. Drop sources into `PrimarySources/`; keep `STATUS.md` files on **Not chosen**.
2. Framestorm starters in `Framing/` — drills, not a pick.
3. Research evidence without assuming which frame wins.
4. Do **not** write a problem statement until the team chooses a problem.
5. When you announce a decision (frame, PS, opportunity, etc.), expect STATUS updates and the
   **immediate** next steps only — see `Preparing-Checklist.md` and `decision-routing.mdc`.
6. Plan/solve only on an explicit ask after the prepare gates.
