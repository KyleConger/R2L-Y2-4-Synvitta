# R2L Y2 4 Synvitta

Market-entry engagement for **Synvitta**: land **one opportunity** and **one customer** for
**research-use-only (RUO)** thyroid and syphilis assays, with a clear **how** and a **90-day plan**.

**Stage:** prepare baseline is in place. Do not start planning until the team asks.

**Hard outs:** no FDA filing strategy, no financial forecast, no national market sizing.

## Provenance

This repository was started from materials and method files taken from a prior Foundations of
Consulting / R2L presentation workspace (Charter case + framestorm–solve kit + class practice).
Charter client work is **not** in scope here. Keep the playbooks and Cursor rules; treat drinkware
canvases as method examples only. Synvitta facts belong in `PrimarySources/`.

GitHub: [KyleConger/R2L-Y2-4-Synvitta](https://github.com/KyleConger/R2L-Y2-4-Synvitta)

## How to use this repo in prepare

1. Drop company, assay, and customer source files into `PrimarySources/` (see AI-INDEX).
2. Update `CORE-INFORMATION.md` with tagged facts only.
3. Framestorm into `Framing/` — drafts, not a pick.
4. Build evidence in `Research/` (assumption register, customer long-list as evidence).
5. Stop at the prepare gate in `Preparing-Checklist.md`. Planning starts on an explicit ask.
