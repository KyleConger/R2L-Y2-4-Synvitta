# Team session runbook (~4 hours)

**Purpose:** stay on the case clock. AI attacks your work (prompt card); it does not write the deck
for you. Attach the case PDF to every prompt. Mark AI output accept / reject / qualify.

**Repo helpers:** `Framing/` · `Research/` · `Preparing-Checklist.md` · `.cursor/rules/decision-routing.mdc`  
**Prompt card:** `PrimarySources/company/synvitta-prompt-card-draft-2026-11-11.docx`  
**Say in chat:** “keep us on track” or “we’re at [block]” — the agent should point to this runbook.

---

## Clock

| Block | Time | Team does | AI (prompt card) | Repo artifact |
|---|---|---|---|---|
| **1. Frame · prioritize · hypothesize** | **0:00–1:00** | Sketch Handout A cuts A/B/C; **first-pass all three opportunities by 1:00**; define criteria; PS → tree → claim + rival | Prompt 1 · 2 · 3 | `handouts/Handout-A-…` · `issue-tree-cuts-handout-a.md` · PS/hypothesis templates · `STATUS.md` |
| **2. Analysis assignments** | **1:00–2:30** (**1:30** per member in parallel) | Each person owns branch-tied work-plan row(s): peers/segments first; data ladder; confirms/kills | Optional: tighten briefs; Prompt 4 Regulatory question list if someone’s route needs it (~2:00) | `Research/analysis-workplan-template.md` · `beachhead-candidates.md` · `regulatory/dated-regulatory-facts.md` |
| **3. Decide** | **2:30–3:00** (**30 min**) | Claim survived? One opportunity + one beachhead + entry mode. Kill what failed. | Do **not** let AI pick for you. Use analysis results only. | Update `Framing/STATUS.md` · `Research/STATUS.md` |
| **4. Build & rehearse** | **3:00–4:00** (**last hour**) | 3–5 slides: opportunity + customer · route + regulatory assumption · 90-day (conversations, small test, 2 metrics, 1 risk) · rehearse | Prompt 5 Prospect check (~2:15) · Prompt 6 Skeptical client (~2:55) | `Deliverables/` · beachhead + solving rules |

**Case budget reminder:** ~four hours total for research, discussion, and presentation prep.

## Block 1 exit criteria (before analysis handoff)

- [ ] Handout A: sketched ≥2 cuts; **first-pass of all three opportunities by 1:00**
- [ ] Criteria defined (FDA status has one home); product×customer not on same level
- [ ] Problem statement passes five tests + **90-day move?** + **value of being right**
- [ ] MECE tree; priorities set; cut rule stated; leftovers named (e.g. licensing/distributors)
- [ ] “This is the root cause…” can be said (even if provisional)
- [ ] Claim + rival drafted (4-hour + 90-day kills)
- [ ] Each teammate has a named analysis assignment (branch + comparison + deadline 2:30)

## Block 3 decide checklist (30 min)

- [ ] Which claim survived analysis?
- [ ] One case option (SynELISA / NBS / custom)
- [ ] One beachhead + entry mode
- [ ] Key regulatory assumption to verify
- [ ] What we are unwilling to claim

## Block 4 deliverable check (must all be on the 3–5 slides)

Full form: `Deliverables/deliverable-check.md`

- [ ] **One opportunity**, **one customer**
- [ ] **Approach** and **regulatory assumption** (to verify)
- [ ] **Three actions**, **2–3 prospects** (real conversations in the plan)
- [ ] **Two metrics**, **one risk**
- [ ] **3–5 slides** only
- [ ] No FDA filing strategy / forecast / national sizing
- [ ] Skeptical-client dry run (Prompt 6)
