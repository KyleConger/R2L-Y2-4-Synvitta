# PrimarySources

Authoritative inputs for the Synvitta case. **Facts only** — no framing, no recommendation.

## Layout

| Folder / file | Put here |
|---|---|
| `CORE-INFORMATION.md` | Tagged fact sheet (start here for AI and humans) |
| `AI-INDEX.md` | Reading order and what each source is for |
| `handouts/` | Handout A (three cuts) + photos |
| `regulatory/` | Dated cannot-claim / FDA / CLIA (not Handout A) |
| `company/` | Case PDF, prompt card, Synvitta materials |
| `assays/` | Thyroid and syphilis RUO product sheets, IFUs, performance summaries |
| `customers/` | Named labs, PIs, cores, public docs about candidate accounts |
| `competitive/` | Incumbent RUO kits, distributor catalog pages |
| `readable/` | Cleaned markdown extracts of awkward PDFs/HTML |

## Rules

- Prefer originals in this tree; put cleaned copies under `readable/`.
- If a markdown extract disagrees with the original, **trust the original**.
- Do not file analysis memos here — those go in `Research/` or `Framing/`.
